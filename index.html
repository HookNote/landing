Preguntas Frecuentes

Si tu webhook devuelve un JSON válido con el campo message y responde con código 200, HookNote mostrará ese mensaje como confirmación. En caso contrario, se guardará el estado HTTP para que puedas revisar el envío.

Detalles técnicos para desarrolladores

Los datos se envían mediante POST al endpoint que configures.

Cabeceras HTTP Personalizadas e inyección segura

Inyecta cabeceras HTTP planas (como Authorization: Bearer o x-api-key) a nivel de endpoint. HookNote no impone integraciones complejas como JWT ni fuerza tipos de Auth, dándote libertad total. Además, dispones de una función reversible para enmascarar los valores sensibles en tu dispositivo y protegerlos de miradas indiscretas, pudiendo revelarlos en cualquier momento.

Texto (JSON)
POST
{
  "kind": "text",
  "text": "Hola este es un mensaje de prueba",
  "ts": 1704803456789
}
Audio (JSON)
POST
{
  "kind": "audio",
  "format": "webm",
  "ts": "1704803456789",
  "file": "(Binary .webm file)"
}

ℹ️ Nota: los audios enviados no se almacenan en el dispositivo tras el envío.
